# 快速开始

## 1. 安装

从 N.E.K.O 插件市场安装，或使用 GitHub Release 中的 `.neko-plugin` 文件。源码 ZIP 不能代替插件包。

启用并启动“炉石猫娘陪玩”后，日志监听默认启动；数据共享、主动解说和独立诊断浮层默认关闭或不自动启动。首次使用还需要在插件的“主面板”完成下面两项操作；“使用指南”页面本身不包含开关。

## 2. 启用 Power.log

返回“炉石猫娘陪玩”的主面板，在顶部“三步开启陪玩”区域点击蓝色“配置日志”，然后在确认框中选择“配置日志”。这个按钮就是启用 `Power.log` 的入口，不需要在炉石游戏内寻找日志开关。

插件会读取 `%LOCALAPPDATA%\Blizzard\Hearthstone\log.config`，首次修改前创建 `log.config.neko.bak`，并补全 Power 日志输出配置。看到“Power.log 配置已检查”后，如果提示有修改，请完全退出并重新启动 Hearthstone；只返回登录界面不够。

默认日志位置是 `%LOCALAPPDATA%\Blizzard\Hearthstone\Logs\Power.log`。日志位于日期/会话子目录时，插件会自动选择最近更新的文件；也可在设置中填写文件或目录绝对路径。

如果主面板的“配置日志”按钮不可用，可在炉石完全退出时手动创建或编辑上述 `log.config`，至少包含：

```ini
[Power]
LogLevel=1
FilePrinting=true
ConsolePrinting=false
ScreenPrinting=false
Verbose=true

[LoadingScreen]
LogLevel=1
FilePrinting=true
ConsolePrinting=false
ScreenPrinting=false
Verbose=false
```

保存后重新启动炉石。不要修改或上传 `Power.log` 本身。

## 3. 确认状态

- `monitor_running = true`：监听线程运行；
- `source_state = watching`：已找到日志；
- `lines_seen` 持续增长：炉石正在写日志；
- `last_error_code` 为空：未发现读取错误。

进入酒馆后，面板会显示单排/双排、阶段、回合、金币、酒馆等级、商店、战团和八人大厅。对手战团若存在，会明确标记为上次观察而非当前状态。

## 4. 启用问答

回到主面板顶部“三步开启陪玩”区域，打开“我明确同意向当前 NEKO LLM 分享经过过滤的公开局势”，再点击“保存陪玩设置”。开关只有保存成功后才生效；状态卡会从“未开启”变为“已开启”。

这项授权是猫娘读取当前局势和回答酒馆建议的必要条件，但不是本地日志监听的必要条件。它允许当前角色在你主动提问时调用只读工具；`target_lanlan` 为空时插件不保存活动角色 ID，由 N.E.K.O 宿主逐消息选择角色。例如：

- “帮我看看现在酒馆玩什么流派比较好？”
- “我现在该稳血还是升本？”
- “这个英雄我本赛季打得怎么样？”
- “刚才这局主要输在哪个节奏点？”

工具会先查当前公开状态、`hsbg.cards` 当前卡池/卡牌事实、官方赛季规则和本机样本，再由角色回答。若问题需要全服胜率，角色会说明当前没有授权数据源，而不是编造。公共卡牌目录默认每日后台更新，不包含牌局或玩家数据；离线时会使用旧缓存并标记陈旧。

## 5. 启用主动陪玩

再打开“启用猫娘 LLM 实时短解说”，角色才会在三连、低血量、战斗或结算等有情绪价值的时机主动说话。普通事件有 25 秒冷却，关键事件有 8 秒冷却；用户聊天后主动解说会安静 30 秒，只有优先级 `>=9` 的关键事件可以绕过静默窗。

关闭主动解说不会关闭问答工具。关闭数据共享会同时停止工具读取、场景上下文和新的主动解说，并恢复日常聊天语境。

随包 `plugin.toml` 只提供安装默认值；N.E.K.O 原生配置服务是唯一运行时设置来源。用户显式填写的 `log_path` 会保存，自动发现的实际日志路径不会保存。状态刷新不会覆盖尚未保存的面板输入；Plugin Store 长期只保存聚合酒馆统计，其 client 生命周期由宿主管理。

## 6. 独立浮层诊断

“打开诊断浮层”和“测试解说”只用于验证透明窗口与消息通道。自动陪玩台词由 NEKO 宿主显示/播放，不会复制到该浮层，因为公开 Plugin SDK 不提供模型最终回复回调。

诊断浮层仅支持 Windows 和带 `tkinter` 的 Python，置顶、透明、点击穿透，并在炉石窗口不存在或最小化时隐藏。它不可用不会影响日志监听、工具或 NEKO 角色回复。

## 7. 停止与卸载

停止监听或停止插件会清理插件拥有的线程/子进程；显式固定目标且已建立场景时还会恢复该角色的日常语境。目标为空时没有跨消息场景需要恢复。卸载不会删除 Hearthstone 日志，也不会自动恢复 `log.config`；需要恢复时，在炉石退出后核对 `log.config.neko.bak` 再手动处理。

问题排查见[故障排查](troubleshooting.md)，数据范围见[隐私与安全](privacy-security.md)。

插件首次接入已有 `Power.log` 时，默认且最多只在本机恢复解析末尾 64 MiB，之后增量跟随。读取到的日志字节不会整体发送给模型，模型只接收隐私文档列明的过滤后公开字段。
